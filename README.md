# こおりくんの スーパーブラックジャック

こおりくんシリーズの スロット。前兆の カジノバトル (ブラックジャック・ポーカー・ルーレット)・こおりチャンス (BJ 昇格パート + ジャッジ)・ストックタイムの ループを ブラウザで 遊べる。もとは ユーザーの 設計書 (2026-11-19)。

公開ページ: https://taku3482yasu-web.github.io/koori-sbj/

## 遊び方
- `index.html` を ひらく (ダブルクリックでも 動く)。スマホでも 遊べる。
- LEVER (Space / Enter) → ストップ 3 つ (Z X C・← ↓ →・1 2 3)。
- ナビが ない ときは 左リールから。左リールの BAR を 枠上〜上段に 狙う。左上段に スイカが 止まったら 中リールに スイカを 狙う。
- こおりチャンスの 昇格パートは 毎ゲーム HIT (H・レバー) か STAND (S)。21 に 近いほど 報酬が 上がる。
- 第3停止を 長押しすると、バトル最終G の カットインが 出る。
- ボーナス準備中に PUSH を 押すと、色で ボーナスの 種類を 示唆。
- 設定 1〜6・メダル +50・オート (目押し付き)・内部状態・演出カスタム (ボーナス演出・シンプルモード・先バレ)。
- メダル・状態・データ (当たり履歴・スランプグラフ) は 自動で 保存 (ブラウザの localStorage)。データ欄の リセットを 2 回 押すと 最初から。確認用の URL (`?rc=1` など) では 保存しない。
- オートは 押すたびに オート → オート 高速 (リール 3 倍速・演出 短め) → オフ。はじめて ひらくと「あそびかた」が 出る (ボタンで いつでも)。音量は 演出カスタム。
- データ欄に 天井までの G 数と 小役カウンター (通常時・RC 高確の 成立役の 回数と 確率。スイカは 設定差 あり)。
- **図鑑** ボタン: 見た 当たり・カジノバトル (しゅるい・相手・勝ち)・演出・設定示唆と、実績 26 個を 集める (`js/ui/collection.js`。一覧は effects.js から 自動で 作る)。データの リセットや 設定変更では 消えない (localStorage `koori-sbj-zukan-v1`)。
- **演出 確認** ボタン: こおりチャンス・ボーナス・ST・バトル・ロングフリーズ (`?freeze=1`)・エンディング (`?ending=1`) などを すぐ 見られる。確認用の 画面では メダル・データ・図鑑を 保存しない。
- 演出カスタムの「光を 弱める」: 点滅を ゆっくり・カットインや 当たりの フラッシュを うすく する (css の `body.calm`)。はじめは 端末の「視差効果を 減らす」設定に あわせる。
- 設定の えらびに「設定 ？ (当てる)」: 設定は ないしょで 打って、「設定を 予想する」で 答え合わせ (見た 設定示唆の メモと スイカ確率つき)。「つぎの 日へ」で 60% 設定変更 (天井 666G に)・40% 据え置き (どちらかは ないしょ)。成績は localStorage `koori-sbj-guess`。
- あそびかたに リール配列表と 役の 一覧 (reels.js・params.js から 作る)。
- 全画面ボタン (⛶)・ホーム画面に 追加 (`manifest.webmanifest`・`sw.js`・`icons/`。ネット優先で、つながらない ときは 保存した ファイルで 遊べる。http で ひらいた ときだけ)。
- 当たり・狙え・ロングフリーズで スマホが 振動 (演出カスタムで オフ)。キー配置は ふつう (Z X C)・左手 (F / A S D)・右手 (J K L)。
- アップデート情報 (`js/ui/updates.js` の LIST。新しい 版が あると NEW)。スマホの 縦画面では 高さに あわせて 液晶と リールを 小さく する。
- エンディング中は 12% で キャラが 出て 設定を 示唆 (effects.js の SETTING_HINT.ending)。
- 音は `js/ui/sound.js` が その場で 鳴らす (ファイル なし)。当たりの 告知音は 初代スロット「おにおにの野望」と 同じ 作り (一発告知 = パチンコの 先バレ音の 録音 `js/sound-heso.js` + ドスッ・確定の キュインキュイン・プレミアの 長い キュイン)。BGM 5 曲は オリジナル。ボーナスと ST の 曲は 種類ごとに 編曲 (準備中・REG・赤7・青7・SBIG・エピソード・SST。`sound.js` の variant)。BGM ボタンで 曲だけ オン/オフ。mp3 を `assets/bgm/` に 置けば そちらが 優先。

## ファイル
| ファイル | 中身 |
|---|---|
| `js/data/reels.js` | リール配列 (設計書 3 章) |
| `js/data/shapes.js` | 停止形と 成立役 → 停止形 (5 章) |
| `js/data/params.js` | 確率・設定差・調整用の 数値 ぜんぶ (4・6〜10 章) |
| `js/data/effects.js` | 演出・示唆の 一覧とキャラ名 (14 章) |
| `js/engine/*.js` | エンジン (DOM に ふれない・node でも 動く): 抽選・リール制御・カジノバトル・こおりチャンス・演出の 抽選 |
| `js/ui/*.js` | 画面 (リール・液晶・パネル・効果音・入力) |
| `assets/` | 差し替え素材 (図柄・キャラ絵・曲)。置いたら `assets/assets.js` に 名前を 書く |
| `tools/test.js` | テスト (`node tools/test.js`、短く `--quick`) |
| `tools/sim.js` | 機械割 シミュレーション (`node tools/sim.js 4000000 1-6`) |

## 機械割 (各 400 万G・左 BAR 狙い・ナビ通り・17 以上で STAND、4 回の 平均)
設定1 約 98.7%・設定6 約 112.6% (設計書の 目安: 設定1 98〜100%・設定6 111〜113%)。1 回ごとに ±1〜2% ぶれる。
